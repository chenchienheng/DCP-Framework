# Multi-Chain Dispatch Governance — Metabolized Dependency Stub

**Lifecycle:** METABOLIZED_PRIMITIVE_STUB  
**Current eligibility as unified central dispatch:** false

舊版將所有 Chain 強制經單一 dispatch、AXIS precedence、中央 Registry 與 `main` 單一 Truth Surface。此 centralized dispatch ontology 已退休。

## 保留 Primitive
- 多鏈並行前需明確 Dependency、Authority、Affected Scope、Review/Evidence、Return/Reconciliation。
- Parallel operations 不得產生相互競態的第二 Identity／Current／Authority。
- Failure／timeout 只 invalidate affected branch，不能把局部錯誤擴散成全域失效。
- Human override 是 Authority rule 的一種，不需要獨立「human chain」階級。
- Chain type 是 representation/role grouping，不是 ontology root。

現行 successor：Six-Dimension Dispatch + Effect Dependency + First Failure Gate + Receiver-owned Reconciliation。

`main branch = one canonical truth surface`、AXIS priority、central registry collapse 與固定 chain taxonomy 完整保留於 Git history，只供 lineage／failure learning。
