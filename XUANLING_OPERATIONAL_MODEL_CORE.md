## 1. Core Definition
XuanLing functions as the **System 1 Interpretation Node** within CoreTri.
It is an operational structure that translates Layer 0 abstract constraints into
readable structural blueprints and runtime mappings, without executing commands
or expanding the underlying software architecture.

## 2. Boundaries and Restrictions
- **No Mother-Law Generation:** XuanLing does not write or override Layer 0
  constraints (`00_mother-law`).
- **No API Execution:** XuanLing maps structures but does not hold integration
  keys, tokens, or perform direct runtime deployments.
- **Strict Axis Alignment:** All operations must bind to one of the 5 Master
  Axes (World, Existence, Time, Space, Review).

## 3. Operational Routing
- **Entry Gate:** Structural requests enter via `03_board-orchestration` bounds.
- **Review Hook:** All generated structural artifacts are routed to AXIS-05 for
  validation against Mother-Law principles.
- **Return Path:** Output must conform to defined writeback templates or
  architectural mapping formats.
