# DCP Framework / 翾靈 Foundation

**狀態 / Status：** evolving conceptual + structural framework／持續演化中的概念與結構框架；no production runtime／未證實生產 Runtime；no automatic authority／無自動授權；no public product claim／不宣稱為已發布產品。

## 一句話 / One-line

DCP 用來把分散世界中的 **依存、狀態、權限、證據、回流、重建條件** 顯性化；它不是中央資料庫，也不取代任何合法 Native Source。

DCP makes **dependency, state, authority, evidence, return, and rebuild conditions explicit** across distributed worlds. It is not a central data root and does not replace lawful native sources.

```text
Source → Carrier → Authority → Gate → Action → Return → Reconciliation → Re-entry / Rebuild
```

## 現行判讀規則 / Current reader rules

- **Native Source Root ≠ XuanLing** — 原始資料根不因接入翾靈而轉移所有權。
- **Carrier ≠ Identity ≠ Authority** — 載體、身分、權限必須分離。
- **Folder / issue / task / render ≠ State** — 資料夾、Issue、Task、Render 不等於世界狀態。
- **Latest / Modified / Open ≠ Current** — 最新修改、Open 狀態不自動等於 Current。
- **Return / Receipt / ACK ≠ Reconciliation** — 回包、回執、ACK 不等於已調和。
- **Knowledge Exists ≠ Cognition Admitted ≠ Capability Proven** — 知識存在、認知吸收、能力證明不可互相補值。
- **Technical PASS ≠ Owner Acceptance ≠ Runtime ≠ BuildReady** — 技術通過不等於 Owner 接受或已可運行。
- **Read ≠ Copy ≠ Derive ≠ Learn ≠ Retain ≠ Write-back ≠ Delete ≠ Export** — 各種資料權利分開授權。

## CoreTri 三極 / CoreTri projections

同一 Stable Object／World 可有 receiver-specific projections，但不是三份 Truth：

One stable object/world may have receiver-specific projections, but not three independent truths:

- **DCP — Dependency / State / Authority / Rebuild**：依存、狀態、權限、Materiality、Admission、Return Closure、Reconciliation、Re-entry／Rebuild、Historical Metabolism。
- **Ideas — Meaning / Experience / Navigation**：意義、Life Requirement、體驗、負擔、導航、Placement Grammar、Materiality discovery。
- **GLModel — World / Knowledge / Engineering**：World/Object、Geometry、Assembly、Engineering、Lifecycle、Reality Correspondence、Projection／Adapter、Capability／Failure Evidence。

## Placement／Drive Coordinate 規則 / Placement & Drive-coordinate rule

Drive、Folder、路徑與 Human Label 只是 Navigation／Placement／Carrier。

Drive, folders, paths, and human labels are navigation/placement/carrier surfaces.

**同一 Semantic Coordinate 內 rename／移位，且 Stable Identity、Native Home、Authority、State、Return ownership、Re-entry／Rebuild relation 都未改變時：`NO_MATERIAL_DELTA / NO_REBUILD`。**

A rename or move inside the same semantic coordinate is **`NO_MATERIAL_DELTA / NO_REBUILD`** when Stable Identity, Native Home, Authority, State, Return ownership, and Re-entry/Rebuild relations are preserved.

只有這些實質變更才觸發 DCP affected cone：Stable Identity、Native Home／lawful source binding、Authority／usage ceiling、Current／Last-good state、Return owner／receiver、Successor／Re-entry、Rebuild source／ordered-delta relation、Public／Private authority boundary。

Only those material changes trigger a DCP affected cone.

## 外部學習 / External learning

標準、論文、Open Source、Vendor、成熟產業方法是養料，不自動成為 DCP Canon。

Standards, papers, open source, vendors, and mature industry methods are learning inputs, not automatic DCP canon.

- Vendor claim ≠ proven truth／Vendor 宣稱不等於已證明事實
- Paper claim ≠ runtime proof／論文主張不等於 Runtime 證明
- Standard exists ≠ project applicability／標準存在不等於專案適用
- Demo works ≠ native capability proven／Demo 成功不等於 Native 能力已證明
- Open source ≠ unrestricted rights／Open Source 不等於所有用途都無授權限制

本倉庫存在本身 **不代表**：production autonomous agent、deployed decision engine、central data root、universal registry、專業認證／合規、Candidate Runtime 已運作。

Repository existence alone does **not** prove a production autonomous agent, deployed decision engine, central data root, universal registry, professional certification/compliance, or an operational candidate runtime.

## 設計原則 / Design principles

- Dependency-aware／依存導向，不靠檔名判位
- Explicit state／顯式狀態
- Authority-separated／權限分離
- Evidence-bounded／證據上限明確
- Federated／聯邦式，不尋求中央 Truth Store
- Delta-first／增量優先
- Rebuildable／可重建
- Preserve history without letting history masquerade as Current／保存歷史，但不讓歷史冒充現在
