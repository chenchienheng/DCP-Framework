固定：

`Extension ≠ Taxonomy`  
`Folder ≠ Ontology`  
`Carrier ≠ Identity`  
`Representation ≠ Truth`

`Stable Existence → Function/Capability → Dependency/Constraint → State → Authority → Evidence → Effect/Return → Reconciliation → Rebuild/Metabolism`
