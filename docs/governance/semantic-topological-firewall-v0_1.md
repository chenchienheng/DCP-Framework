# Semantic Topological Firewall v0.1

Status: Candidate / Governance Note / No Runtime

## Core

This firewall is not block-only. It routes valid action through source, carrier, authority, gate, return, and rebuild.

## Sequence

```text
Block -> Explain -> Route -> Escalate -> Return
```

## Blocks

- wrong context
- wrong authority
- wrong carrier
- wrong state
- missing return
- platform lock-in

## Allows

- bounded candidate work
- sanitized design
- human-gated trial
- reversible patch
- returnable change

## Red Doors

- Blocking is not governance.
- Exception request is not violation.
- Valid improvement is not intrusion.
- Capability is not permission.
