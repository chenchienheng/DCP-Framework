# Semantic / Topological Firewall v0.1 Candidate

Status: Candidate / Governance Note / Not Doctrine / No Runtime

## Core

The XuanLing firewall is not block-only. It is a semantic and topological gate system.

```text
Block -> Explain -> Route -> Escalate -> Return
```

## What It Blocks

- wrong context
- wrong authority
- wrong carrier
- wrong state promotion
- wrong return path
- wrong platform binding

## What It Should Not Blindly Block

- sanitized candidate design
- human-gated small trials
- reversible improvements
- changes with evidence, owner, and return path

## Topological Questions

```yaml
Firewall_Check:
  where_is_the_cell:
  who_can_see:
  who_can_edit:
  who_can_decide:
  what_gate_blocks_it:
  where_does_it_return:
  does_it_pollute_core:
  does_it_need_escalation:
```

## Red Doors

- Blocking != Governance.
- Wall != Gate.
- Exception Request != Violation.
- Improvement Candidate != Intrusion.
- Spend Approval != Data Authorization.
- Field App Pattern != Root Doctrine.

## Final Rule

A good firewall does not only stop actions. It routes safe action under visible authority and return conditions.
