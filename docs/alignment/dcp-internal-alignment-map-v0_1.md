## Core Role

DCP is the root governance carrier. It should hold generalized rules, red doors, signal governance, memory governance, carrier manifest, production routing, output planning, and domain-pack gates.

It must not hold private field context, raw company data, real customer data, or public-release claims.

## Must Not Store

- private origin details
- private relationship context
- company raw data
- formal BIM / CAD model
- customer data
- credentials / secrets
- small-field private operations
- public release claims

- DCP != Dumping Ground.
- DCP != Fieldspace Store.
- DCP Candidate != Approved Doctrine.

## Final Rule

DCP should remain the generalized root carrier. Field-specific or private content must be represented only as pointers, red doors, or abstracted rules.
