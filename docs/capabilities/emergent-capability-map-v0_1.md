# Emergent Capability Map v0.1

Status: Candidate / Capability Map / No Runtime / No External Writeback
Use As: QHA reading map for capabilities emerging from GitHub / Drive / GPT / LOR / field carriers
Do Not Use As: product roadmap approval, runtime claim, public release, or merge approval

## Core

New capability should not mean more tools. New capability means the chain can read, classify, route, return, compress memory, and call Vitas only when decision is needed.
