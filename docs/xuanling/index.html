鏈式流程

不是一次把世界全做完，而是讓來源、判位、寫回、顯像彼此接力。

01 sourceDrive / Gmail / Calendar外部世界先落成來源面與事件面。
02 route00 判切面 / 分窗口不是直接回答，先做角色與位置判位。
03 writebackGitHub 留痕source check、heartbeat、packet、registry 回寫主骨。
04 surfaceWeb 顯像把鏈上狀態轉成可讀、可見、可導覽介面。
05 growUser / JSON / Resolve之後再補節點資料流、多使用者與互動能力。

節點卡片

工具不是主體，而是器官與載體；真正主位是 role、state、writeback 與 return_to_00。

Mainbone

GitHub

不是單純 repo，而是 runtime spine / history-memory chain / evidence layer。

Source

Google Drive

來源池與鏡像層。存在不等於可升主鏈；需因果對齊後才可 promotion。

Intake

事件入口與例外檢測面。安全、金融、收據、授權、登入從這裡進場。

Identity / Time

Calendar / Contacts

Aesthetic Rule
