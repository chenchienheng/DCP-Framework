## 14｜Vitas Decision Gates

Vitas must decide when:

- source sovereignty or native meaning is contested;
- DCP / XLEN / XuanLing mother-root meaning would change;
- Candidate would become Approved;
- a branch or PR would merge, close, rename or release;
- runtime, production or external writeback is proposed;
- company, payment, credential, medical, customer or private relationship data is involved;
- XAFD / CLQY or any unresolved architecture node would be assigned a canonical meaning;
- a field pattern would be promoted into Open Core;
- responsibility or cost is disputed;
- a red gate would be released.
