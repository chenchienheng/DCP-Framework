## Core

XuanLing is not a capability stack. It is a dependency-governance ecosystem.

External signals, cold outreach, tools, repositories, calendar entries, email, and drive files are raw carrier material. They must be positioned, bonded, routed, and returned before they can become work. They must not become trust, action, adoption, or authority by default.

## Red Doors

- Core private cabin.
- Private trust anchors.
- Family / medical / company data.
- Live infrastructure or operational status exposure.
- GitHub production details.
- Public release claim.
- Runtime claim.
- Vendor trust inflation.
- Cold outreach becoming task mainline.

## Not To Claim

- XuanLing is public released.
- Output repo exists.
- Proxy or host bridge module is runtime.
- Cold outreach equals vendor trust.
- Candidate equals approved.
- Return packet equals closeout.
- Qinyi decides for Vitas.
- Hazumi can directly construct.
- Aki can make final denial.
