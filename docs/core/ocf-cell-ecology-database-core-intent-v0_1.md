# OCF Cell Ecology Database Core Intent v0.1

Status: Candidate / Core Intent / Not Doctrine / No Runtime

## Core

OCF Cell Ecology Database is not an enterprise governance SaaS and not a conventional SQL database product. It is a candidate way to model events as dependency cells with source, local context, sovereignty, gates, returns, and next cells.

## Intent

```yaml
OCF_Cell_Ecology_Database:
  purpose:
    - "model events as cells"
    - "preserve authority and return path"
    - "allow field projection without leaking private context"
    - "turn errors into rebuild material"
  not:
    - "enterprise governance SaaS"
    - "production database"
    - "company system"
    - "runtime platform"
```

## Cell Principle

A cell is not a row. A cell is a bounded life unit with state, authority, action boundary, and return hook.

## Red Doors

- OCF Cell Ecology Database != Enterprise Governance SaaS.
- Cell != SQL Row.
- Field Projection != Public Product.
- Candidate Schema != Production Database.
- Private Field Context != Core Content.

## Final Rule

OCF should remain a substrate grammar until field proof and return audit justify promotion.
