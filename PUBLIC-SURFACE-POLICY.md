# 公開表面規則 / Public Surface Policy

## 中文／Owner View
本公開倉只提供 **public-safe structural projection**：讓外界理解方法、限制、驗證方式與可引用成果；不公開足以重建翾靈內部 Core 的完整依存拓撲、Authority 編排、Rebuild routing、Cognitive Memory compiler、私有 evidence lineage 或 internal machine contract。

中文是 Owner／Human Surface；此公開倉的中文內容用於 Vitas 與協作者快速判讀，但「看得到」不等於「可對外發布」。

## English／External View
This public repository exposes only a **public-safe structural projection**: concepts, limitations, validation methods, and release-safe artifacts. It does not expose the complete internal dependency topology, authority routing, rebuild logic, cognitive-memory compiler, private evidence lineage, or internal machine contracts needed to reconstruct the XuanLing core.

English is the external/public-facing surface. Public-safe content is still subject to release authority and claim ceilings.

## Machine／Canonical View
Machine fields remain canonical and minimal on public surfaces. Public metadata may include stable artifact IDs, state, version, evidence pointer, license, and release state, but must not reveal private internal routing or sensitive Native Source relationships.

```yaml
surface: public
language_human: zh-TW
language_external: en
machine_form: canonical-minimal
release_state: public-safe|public-approved
native_body_embedded: false
internal_core_reconstructable: false
```

## Fixed separations
- Bilingual ≠ Full Disclosure
- Public-safe ≠ Public-approved
- Machine-readable ≠ Public-readable
- Public repository ≠ Native Source Root
- Published method ≠ complete internal implementation
