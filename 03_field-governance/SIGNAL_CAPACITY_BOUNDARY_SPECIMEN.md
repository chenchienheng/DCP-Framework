# Signal Capacity / Boundary Specimen

**Lifecycle:** HISTORICAL_PRIMITIVE_SPECIMEN  
**Current eligibility:** false

Neutral successor for the retired Third Field carrying-layer ontology.

Retained primitives:
- Incoming signal/action requires carrying-capacity checks: type, weight, target capability, privacy/evidence boundary, overload risk and return path.
- Insufficient capacity may HOLD, REDIRECT, DOWNGRADE or REJECT the affected branch.
- Buffering/quarantine is a lifecycle-state or circle function, not a permanent extra ontology layer.

Current successor: Boundary-first + First Failure Gate + Lifecycle State + Circle/Authority/Cloud dispatch.

Full historical Third Field wording remains in Git history only.
