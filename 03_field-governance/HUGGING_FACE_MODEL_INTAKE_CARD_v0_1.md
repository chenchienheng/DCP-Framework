## Retained primitives
任何外部 Model／Dataset／Paper／Code／Space／API／Binary／Media／CAD/BIM asset／Benchmark／Documentation 進入生態時，先判：
- Stable source / publisher / revision / provenance
- Asset type / modality / capability / limitation
- License / rights / privacy / data boundary
- Cost / compute / deployment / mutation authority
- Evidence role / claim ceiling
- Intended use / prohibited use
- Receiver / return / re-entry state

External popularity、open weights、benchmark、可下載、可執行、可連接，都不等於 fit、Authority、Proof、Admission 或 Runtime。

## Successor binding
`External Asset → Source Eligibility → Rights/License/Privacy → Capability & Limitation → Evidence Role/Claim Ceiling → Materiality → Receiver Candidate/HOLD/Reject → Return/Reconciliation`
