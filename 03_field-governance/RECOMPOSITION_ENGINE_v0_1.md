# Constraint-Bounded Recomposition — Primitive Specimen

**Lifecycle:** RETAINED_PRIMITIVE / SUCCESSOR_COMPILATION_CANDIDATE  
**Current eligibility as standalone engine/service:** false  
**Runtime:** false

舊版將 Knowledge Molecule、Co-Field、Linear、GitHub、Commander、AEO 等綁成一個 Recomposition Engine。固定工具與角色已退休；保留「依約束重組、而非依資料量拼接」的核心能力。

## Core primitive
`Intent/Task + Stable Context + Boundary/Authority + Eligible Evidence/Capability Units + Required Output Effect → Filter → Compatibility/Fidelity → Compose → Verify Claim Ceiling → Representation → Receiver Return`

### Filter
- 排除超出 rights/privacy/authority/scope 的單元。
- Missing source/lineage/evidence 的單元 HOLD，而非偷升格。
- Pending／historical／candidate 必須保留 lifecycle state。

### Compatibility / fidelity
- 不同 Source、State、Authority、Representation 先過 Compatibility。
- Composition 後必須能 back-map 到 Stable Existence／Source／Evidence，維持 Fidelity。
- Local success 不自動形成 Global closure。

### Composition
輸出可以是 prose、matrix、task、code、query、CAD/BIM view、dataset slice、chart、image/video composition、API payload、PR/Issue packet、world-model projection 等；格式是 Representation Carrier，不改變 claim ceiling。

### Return
每次 material composition 必須保留：used/held units、boundary、evidence pointers、loss/transform record、receiver、return state、rebuild impact。

## Anti-drift
- Weak signal ≠ fact
- Capability ≠ Authority
- Search/retrieval hit ≠ admission
- Output format ≠ evidence strength
- Tool availability ≠ execution permission
- Return written ≠ receiver reconciled
