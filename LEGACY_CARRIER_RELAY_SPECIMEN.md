# Legacy Carrier Relay Specimen

**Lifecycle:** HISTORICAL_CARRIER_SPECIMEN

**Runtime / Authority / Promotion:** false

This artifact preserves the reusable cross-carrier coordination primitives formerly carried by the `CLOUDTOP_RELAY_CHANNEL_SPEC.md` generation while retiring the old CloudTop/control-center naming from the active repository surface.

## Retained primitives
- Cross-carrier coordination requires auditable Source / Authority / Purpose / Risk / Action / Evidence / Return relations.
- Each carrier retains native IAM, data, model, and operational ownership.
- Receive ≠ Act; Capability ≠ Authority; Public-safe ≠ Public-approved.
- Tool/model/window bindings are replaceable and context-dependent.
- Failure should remain bounded and return to receiver-owned reconciliation.

## Retired assumptions
- A central CloudTop control center is a stable ontology.
- Vendor/model names define permanent roles.
- A fixed relay sequence is universal.
- Cross-cloud coordination acquires source-data sovereignty.
