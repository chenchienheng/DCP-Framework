## Retained primitives

外部人、模型、Agent、SaaS、API、資料庫、感測器、媒體或其他 Carrier 進入翾靈時，只能先作 Capability／Evidence／Execution／Representation candidate。

每個 binding 至少應能判：
- Stable identity / source provenance
- required capability / intended effect
- native receiver / affected scope
- authority / rights / privacy / release boundary
- input/output representation and transform loss
- evidence / claim ceiling
- cost / quota / rate / safety constraints when material
- failure containment / rollback or hold path
- receiver-specific return / reconciliation / rebuild

## Current rules

- Tool ≠ Task。
- Carrier ≠ Identity。
- Agent / Expert / Model ≠ Authority。
- Provider availability ≠ capability internalization。
- External output ≠ Truth／Current／Approval。
- GitHub／Drive／Docs／Calendar／Slack／DB／API 等皆只是可能 Carrier，不建立永久器官。
- 不要求所有 external input 經單一 World Axis／Review Axis／Registry。
- 同一 capability 可依 Need 換 Carrier；換 Carrier 時重新驗證 rights、fidelity、evidence、cost、mutation authority 與 return path。
- 外部 capability 若消失，Stable Life 不應因 provider 消失而失去 Identity；無 successor 時保持 dependency debt / HOLD。
