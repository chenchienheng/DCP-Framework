## Current rule
先辨識 Stable Existence／Required Effect／Authority／Evidence／Return，再選合法 Capability／Carrier。GitHub、Drive、Mail、Calendar、LINE、Replit、Gamma、API、DB、CAD/BIM、Spreadsheet、Media、Local runtime 等只是可替換 carrier/tool profile。

`Tool name ≠ taxonomy`  
`Adapter folder ≠ ontology`  
`Carrier capability ≠ authority`

新的 carrier integration 不應因品牌或副檔名自動建立永久檔案 family。只有具有獨立 contract/evidence/failure/interop value 時才保留專屬 specimen；否則其能力應吸收入 carrier-neutral successor。

現行 successor：`LIFECYCLE_DEPENDENCY_CHAIN_KERNEL.md`。本資料夾待完成 unique evidence／pointer／caller／retention census 後，再進 unified reclaim/manual-move review。
