# Label Topology Map — Historical Hygiene Stub

**Lifecycle:** HISTORICAL_HYGIENE_STUB  
**Current eligibility as governance map:** false

舊版把大量 GitHub labels 映射到 MotherTree／13-gate／closure／tool-family，並以 Green/Yellow/Red 作風險語義。這份 mapping 是當時的 hygiene proposal，不應再成為現行 ontology 或權限來源。

## 保留 Primitive
- Label 是工作管理 metadata，不是 Identity／Authority／State 本體。
- Risk/impact 可作 triage signal，但不能只靠 label 顏色授權行動。
- Duplicate／merge／deprecate label 應依實際 issue/PR usage 與 successor 判斷，不靠名稱推論。
- Tool/model/platform label 只描述 Cloud/Capability projection，不形成固定角色。

現行 successor：Domain/Authority/State/Circle/Pole/Cloud + platform-native label metadata + Boundary-first risk assessment。

完整舊 MotherTree／Commander／Legion／Nine-Palace label table 保留於 Git history，只供 repo archaeology／audit。
